# Hướng dẫn thay ảnh của Dì và Nhạc nền 🎂

Bạn hãy bỏ các file ảnh của dì vào đúng thư mục `images` này với tên gợi ý như sau (hoặc sửa tên trong file `index.html`):

1. `images/di-1.jpg` -> Ảnh đại diện chính & tấm ảnh thứ 1 trong album Polaroid
2. `images/di-2.jpg` -> Tấm ảnh thứ 2 trong album Polaroid
3. `images/di-3.jpg` -> Tấm ảnh thứ 3 trong album Polaroid
4. `images/di-4.jpg` -> Tấm ảnh thứ 4 trong album Polaroid

*(Lưu ý: Nếu bạn chưa kịp bỏ ảnh vào thư mục `images/`, trang web sẽ tự động hiển thị ảnh mẫu lung linh để không bao giờ bị lỗi vỡ hình!)*

## Về phần nhạc nền Loop 🎵
- Mặc định trang web đã có bộ phát nhạc **Happy Birthday Music Box & Piano** tự động lặp vô tận (Loop 100%).
- Nếu bạn muốn chèn thêm file nhạc `.mp3` riêng (ví dụ: `nhac-sinh-nhat.mp3`), bạn chỉ cần bỏ file `nhac-sinh-nhat.mp3` vào cùng thư mục với `index.html`, code đã hỗ trợ sẵn thẻ `<audio loop>` tự động phát lặp lại!
